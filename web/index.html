TRANSACTIONAL RESTORE

                
Selected backup

                

                  A successful dry run is required before the restore button
                  is enabled. Applying changes creates an automatic
                  pre-restore checkpoint.
                

                

                  A full restore replaces users, sessions, API tokens, TOTP,
                  and client-certificate mappings. This browser session may
                  end before the final job result can be retrieved. Prefer
                  the local console and janusgatectl for recovery.
